## 目标

将 2640 个 commit 的历史压缩为仅含最后一次 commit 内容的全新单 commit 历史,远程指向 https://github.com/Ero-Cat/VRCX-Cloud.git,不推送。

## 现状

- 本地仅 `master` 分支(HEAD = f13faa558),与 origin/master 同步,无 tag、无 stash
- **远程 origin 已经是该 URL,无需改动**(仅验证)

## 步骤

1. **创建无父历史的孤儿分支**
   `git checkout --orphan fresh-root`
   (index 和工作区保持 master 当前内容不变)
2. **复用最后一次 commit 的信息提交**
   `git commit -C f13faa558`
   (保留原 commit 的 message、作者、作者日期;commit hash 必然改变,因为父提交信息不同)
3. **用新分支替换 master**
   `git branch -M master`
4. **验证**
    - `git log --oneline` 只剩 1 个 commit
    - `git diff f13faa558 HEAD` 输出为空,证明文件内容与原最后一次 commit 完全一致
    - `git remote -v` 确认远程 URL
5. **不推送**。保留 master → origin/master 的跟踪配置,之后推送只需 `git push -f origin master`

## 说明

- 旧 commit 对象在本地 reflog/GC 前仍可恢复,是天然的撤销窗口;如需彻底清除本地残留,可额外执行 `git reflog expire --expire=now --all && git gc --prune=now`(可选,不默认执行)
- 未跟踪的 `.DS_Store` 保持原样,不纳入提交
